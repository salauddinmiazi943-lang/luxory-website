Imported into src/lib/bangladesh-locations.json:
- 8 divisions
- 64 districts
- 502 upazila records
- 74 records typed as metropolitan thana

Only the Division -> District -> Upazila/Thana hierarchy is included. Union,
area, ward, village, boundary, coordinate, alias, and postal-code data is not
included in the checkout dataset.

The upstream README describes the hierarchy as compiled from the bd_geo_code
database and public sources; it also references ISO 3166-2:BD codes, Wikidata,
geoBoundaries, and Bangladesh Post Office postal-code lists. It is not an
official government publication and warns that some names, spellings, and
other values may be incorrect.

The upstream README says 67 city thanas were added, while the pinned
data/bd_locations.json actually contains 74 records with type "thana". The
import and validation use the count present in the pinned data file. This
count discrepancy is unverified and is not a claim that every metropolitan
police station has been included.

Upazila BBS-code coverage in the upstream metadata is reported as 466 of 502;
newer administrative units may not yet be present in that register. The
dataset's "fullCode" values are stable internal identifiers, not a guarantee
that every record has an official BBS code.
